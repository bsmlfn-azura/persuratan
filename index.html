Panduan Setup Google Spreadsheet

1

Buat Google Spreadsheet Baru

Buka Google Sheets dan buat spreadsheet baru. Beri nama misalnya "Arsip Surat".

2

Buat Dua Sheet

Buat sheet "Surat Masuk" dengan header: Timestamp, Nomor Surat, Tanggal Surat, Tanggal Diterima, Pengirim, Perihal, Keterangan, Link PDF

Buat sheet "Surat Keluar" dengan header: Timestamp, Nomor Surat, Tanggal Surat, Tujuan, Perihal, Keterangan, Link PDF

3

Buka Apps Script

Klik menu Ekstensi > Apps Script. Hapus semua kode default, lalu tempel kode di bawah ini:


                                    

                                

                            


                            

                                
4

                                

                                    
Ganti Folder ID

                                    
Di baris atas kode, ganti GANTI_DENGAN_FOLDER_ID dengan ID folder Google Drive untuk menyimpan PDF. Cara mendapatkannya: buka folder di Drive, salin ID dari URL.

                                

                            


                            

                                
5

                                

                                    
Deploy sebagai Web App

                                    
Klik Deploy > New deployment. Pilih type Web app. Set "Execute as" ke Me dan "Who has access" ke Anyone. Klik Deploy, lalu salin URL-nya.

                                

                            


                            

                                
6

                                

                                    
Tempel URL di Atas

                                    
Tempel URL deployment ke kolom "URL Google Apps Script" di form kiri, lalu klik Simpan. Selesai!
